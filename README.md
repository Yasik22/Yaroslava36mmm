# Листя — навчальний інтернет-магазин

Готовий статичний лендінг українською мовою. Це вигаданий магазин, створений для домашнього завдання з програмування. Реальні замовлення й оплата відсутні.

## Як відкрити
Двічі натисніть index.html. Інтернет для показу сторінки не потрібний: стилі, скрипти й фотографії містяться в папці сайту. Кошик демонстраційний і очищається після перезавантаження сторінки.

## Як завантажити на GitHub Pages
1. Увійдіть на https://github.com та створіть новий публічний репозиторій, наприклад lystia-shop.
2. Розпакуйте ZIP-архів. У репозиторії натисніть Add file → Upload files.
3. Завантажте ВМІСТ папки lystia: index.html, css, js, images, LICENSE, README.md та .nojekyll. Файл index.html має бути в корені репозиторію, а не всередині додаткової папки lystia.
4. Натисніть Commit changes.
5. Відкрийте Settings → Pages. У розділі Build and deployment виберіть Source → Deploy from a branch, гілку main, папку / (root), натисніть Save.
6. Дочекайтеся завершення публікації. Посилання з'явиться в Settings → Pages. Зазвичай адреса має вигляд https://ВАШ-ЛОГІН.github.io/lystia-shop/ .

## Структура
- index.html — головна сторінка, тексти та товари.
- css/bootstrap.css — стилі завантаженого шаблону, включно з Bootstrap.
- css/styles.css — оформлення вигаданого магазину й адаптація до мобільних екранів.
- js/scripts.js — демонстраційний кошик.
- images/ — локальні фотографії.
- LICENSE — ліцензія оригінального шаблону MIT.

## Що змінено у шаблоні
Використано безкоштовний Shop Homepage від Start Bootstrap:
https://startbootstrap.com/template/shop-homepage
Джерело: https://github.com/StartBootstrap/startbootstrap-shop-homepage
Збережено принцип побудови: навігація, головний блок, адаптивна сітка карток Bootstrap та підвал. Замінено назву, мову, тему, тексти, товари, ціни, зображення й посилання. Додано власні стилі, блоки «Про нас» і «Догляд», навчальне застереження та демонстраційний кошик.
